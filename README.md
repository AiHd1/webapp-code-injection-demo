# Web Application Code Injection Demo

This project demonstrates a simplified example of code injection in web applications. It includes a vulnerable web application and a script to exploit this vulnerability. The project is intended for educational purposes only.

## Setup

1. Clone the repository.
2. Install the dependencies: `pip install -r requirements.txt`
3. Run the web application: `python app.py`
4. Use the exploit script to see code injection in action: `python exploit.py`
